# CS-340-Project-Two

The CRUD module can be changed to use different accounts and databases. It can also be changed to take input from the dashboard to log in to a database.
The documentation will help others modify the program in the future. The dashboard was created one requirement at a time. I reused elements and code 
from a previous project. After each requirement, I would test to see if I succeeded in implementing the requirement. Whether it was creating the 
dashboard or a CRUD module, I look at it the same way as shoveling dirt, cleaning a room, or performing an experiment. I will make progress at a slow
and constant pace. With this project, I am cleaning up and easing the work of others with a convenient tool. That tool needs consideration for the user,
ease of use, and efficiency.
